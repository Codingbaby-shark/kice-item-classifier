# KICE 수능 출제 지침 기반 문항 분류 및 평가 자동화 시스템

한국교육과정평가원(KICE) 대학수학능력시험(수능) 및 모의평가·전국연합학력평가 출제 지침과 **이원목적분류표(내용영역 × 행동영역)** 체계를 기반으로, 시험지나 문항 파일을 입력하면 각 문항의 **내용영역(15개정/22개정 구분), 행동영역, 학년별 맞춤형 난이도, 문항별 출제 검토 의견**을 자동으로 분류·평가하는 웹 애플리케이션입니다.

## 핵심 기능

1. **2015 개정 vs 2022 개정 교육과정 완벽 구분 ([kice_frameworks.json](file:///Users/minsu/Documents/Codex/문항분류/data/kice_frameworks.json))**
   - **2015 개정 교육과정 (현 고3 · 올해 수능 적용)**:
     - 수학: `수학(고1)` · `수학 I` · `수학 II` + 선택(`확률과 통계` · `미적분` · `기하`)
     - 국어: 공통(`독서` · `문학`) + 선택(`화법과 작문` · `언어와 매체`)
     - 사탐·과탐: 17개 선택과목 체제(`물리학I·II`, `화학I·II`, `생명과학I·II`, `지구과학I·II` 등)
   - **2022 개정 교육과정 (현 고1·고2 · 개편 수능 및 학력평가 적용)**:
     - 수학: `공통수학 1·2(행렬 신설/복원 포함)` · `대수(구 수학I)` · `미적분 I(구 수학II)` · `확률과 통계(수능 공통)` · `미적분 II · 기하(진로선택)`
     - 국어: `공통국어 1·2` · 수능 통합(`독서와 작문` · `문학` · `화법과 언어`)
     - 사탐·과탐: `통합사회 1·2` · `통합과학 1·2` 및 22개정 일반·진로선택 과목 체제

2. **대상 학년(고1 / 고2 / 고3·N수) 기반 난이도 보정 및 이수 범위 점검**
   - 상단에서 대상 학년(`고3·N수생`, `고2`, `고1`)을 선택하면 해당 학년에 적용되는 기본 교육과정(`고3 → 15개정`, `고1·고2 → 22개정`, 수동 변경 가능)이 자동으로 매칭됩니다.
   - 동일 문항이라도 대상 학년 수험생 집단의 학습 숙련도에 맞추어 **체감 난이도 등급, 예상 정답률, 예상 1등급 컷**을 보정하고, 미이수 상위 학년 개념이나 교육과정 외 요소가 포함되었는지(`curriculum_check`) 판정합니다.

3. **별도 API 키 없이 구독 중인 Codex CLI / Claude Code CLI 로그인 세션 활용 ([analyzer.py](file:///Users/minsu/Documents/Codex/문항분류/analyzer.py))**
   - **🟢 Codex 구독 세션 (`codex exec`)**: 로컬에 로그인된 ChatGPT/Codex 구독 세션 토큰을 그대로 활용하여 별도 API 키 없이 문항 텍스트 및 이미지를 분석합니다.
   - **🟣 Claude Code 구독 세션 (`claude -p`)**: 로컬에 로그인된 Claude Code 구독 세션 토큰을 그대로 활용하여 분석합니다.
   - **🔵 Google Gemini API**: 기존처럼 Gemini API Key를 직접 입력하여 사용하는 방식도 지원합니다.

4. **한국교육과정평가원(KICE) 공식 사이트 바로가기 내장**
   - 상단 헤더에 **한국교육과정평가원(KICE)**, **수능·모평 기출문제 자료실(`suneung.re.kr`)**, **국가교육과정정보센터(`ncic.re.kr`)** 바로가기 링크를 제공합니다.

## 실행 방법

```bash
python3 server.py 8080
```

브라우저에서 `http://localhost:8080` 으로 접속합니다.
